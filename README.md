# GeoEtrift

**GeoEtrift** არის Full-Stack ვებ-აპლიკაცია, რომელიც აერთიანებს ელექტრონიკის განცხადებებს წამყვანი ქართული პლატფორმებიდან (Mymarket და Facebook Marketplace) ერთიან, მოსახერხებელ React ინტერფეისში.

პროექტი შექმნილია სასწავლო მიზნებისთვის და აჩვენებს, თუ როგორ შეიძლება მონაცემთა პარსინგი და სუფთა API არქიტექტურის აგება იმ პირობებში, როდესაც პლატფორმებს არ გააჩნიათ საჯარო API.

---

## 🛠️ ტექნოლოგიური სტეკი (Tech Stack)

- **Frontend:** React.js, CSS3 / Tailwind CSS
- **Backend:** Node.js, Express.js
- **Data Parsing:** Cheerio (HTML სტრუქტურის გასაანალიზებლად)

---

## 🏗️ არქიტექტურა და მუშაობის პრინციპი

პლატფორმების მკაცრი ანტი-ბოტ დაცვისა და პრეზენტაციის მაქსიმალური სტაბილურობის უზრუნველსაყოფად, პროექტი იყენებს **ლოკალური მონაცემთა პაკეტების (HTML)** მოდელს:

1. **მონაცემთა ბაზა:** ძიების შედეგების HTML გვერდები შენახულია ბექენდის `data/` დირექტორიაში.
2. **ბექენდ სერვერი:** Node.js/Express სერვერი `Cheerio`-ს დახმარებით კითხულობს ამ HTML ფაილებს, აგროვებს პროდუქტის სათაურებს, ფასებს, სურათებს და გარდაქმნის მათ სუფთა JSON ფორმატში.
3. **ფრონტენდი:** React აპლიკაცია აკეთებს standard API მოთხოვნას (`fetch`) ლოკალურ სერვერზე და მომხმარებელს უჩვენებს მზა, გაფილტრულ მონაცემებს.
